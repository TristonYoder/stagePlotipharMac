# Stage Plotiphar for Mac

Signed and notarized macOS releases of the [Stage Plotiphar](https://plotiphar.com) self-hosted menu-bar app — a self-contained `.app` that bundles its own Node.js runtime, the Next.js server, database migrations, and (optionally) a headless Chromium for PDF export, so it runs on a clean Mac with nothing else installed.

**[Download the latest release →](https://github.com/TristonYoder/stagePlotipharMac/releases/latest)**

This repo hosts release binaries only — Stage Plotiphar's source lives in its main (private) repository. Every release here is built from a tagged commit there, code-signed with a Developer ID certificate, and notarized by Apple, so it runs under Gatekeeper with no extra steps.
